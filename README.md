# Автотесты для API Course

Этот проект реализует автоматизированные тесты для [API Course Test Server](https://github.com/Nikita-Filonov/qa-automation-engineer-api-course). Тесты написаны с использованием **Python**, **Pytest**, **Allure**, **Pydantic**, **Faker** и **HTTPX**. Исходный код тестового приложения доступен на [GitHub](https://github.com/Nikita-Filonov/qa-automation-engineer-api-course).

## Обзор проекта

Цель проекта — автоматизировать тестирование сервера API Course с фокусом на REST API. Автоматизированные тесты
проверяют различные функции приложения, чтобы обеспечить его стабильность и корректность.

Проект специально разработан для API-автотестов и включает лучшие практики, такие как:

- API-клиенты для структурированного взаимодействия с эндпоинтами,
- фикстуры Pytest для переиспользуемых и поддерживаемых тестовых окружений,
- модели Pydantic для строгой валидации данных,
- валидация схем для проверки соответствия API-контракту,
- генерация фейковых данных для имитации реальных сценариев,

Структура проекта следует отраслевым стандартам для обеспечения ясности, поддерживаемости и масштабируемости тестового кода.

## Начало работы



### 1. Клонирование репозитория

Для начала клонируйте репозиторий проекта с помощью Git:

```bash
git clone https://github.com/McSuit/autotests-api.git
cd autotests-api
```

### 2. Создание виртуального окружения

Рекомендуется использовать виртуальное окружение для управления зависимостями проекта. Следуйте инструкциям для вашей операционной системы:

#### Linux / MacOS

```bash
python3 -m venv venv
source venv/bin/activate
```

#### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей

После активации виртуального окружения установите зависимости проекта из `requirements.txt`:

```bash
pip install -r requirements.txt
```

### 4. Запуск тестов с генерацией Allure-отчёта

Для запуска тестов и генерации Allure-отчёта используйте следующую команду:

```bash
pytest -m "regression" --alluredir=./allure-results
```

### 5. Просмотр Allure-отчёта

После выполнения тестов вы можете сгенерировать и просмотреть Allure-отчёт с помощью:

```bash
allure serve allure-results
```
